YouTube Practice Sections

Load a YouTube video, mark precise practice sections, loop them at custom speeds, and share everything through the page URL. This app does not save your practice data in browser storage.

Enter a YouTube URL or open a shared link to load a player.

Fine tune

Select a section, choose start or end, then nudge by milliseconds for tight loops.

Keyboard shortcuts

  • Space Play / pause
  • P Play active section
  • S Set active start
  • E Set active end
  • , Seek −0.1s
  • . Seek +0.1s

No localStorage, sessionStorage, cookies, IndexedDB, or server API are used by this app for practice data. YouTube itself is loaded from the public IFrame API.
